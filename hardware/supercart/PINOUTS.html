J1 — C64/C128 expansion port (rear view of C64)

TOP ROW — numbered side, 22 → 1dimmed = present on connector, not used by this board
Pin 3 tied to VCC and pin A tied to GND on this board (both documented blank/reserved by the generic C64 spec) — precedent from a real, working reference cartridge, adopted 2026-08-21. Lettered pins F/H/J (C64 A15/A14/A13) are real address lines but unused here — this board's flash A13–A19 come from U1's bank register instead, not the C64's own upper address bits.

Decode & bus wiring

EEPLD decode / bank control

  • IO1_N + RW + PHI2 qualify a $DE00 write.
  • D0–D6 latch into BANK0–BANK6 (7 bits → 128 banks).
  • D7 latches into WRITE_ARM.
  • FLASH_OE_N / FLASH_WE_N are combinational — driven by RW/PHI2/WRITE_ARM directly, not by the bank register.

Flash address / data bus

  • C64 A0–A12 → Flash A0–A12 (direct, no GAL).
  • C64 D0–D7 → Flash DQ0–DQ7 (direct).
  • U1 BANK0–BANK6 → Flash A13–A19 (selects the visible 8 KB page).
  • /ROML → Flash /CE, directly on the PCB (not through U1).
  • /OE ← FLASH_OE_N, /WE ← FLASH_WE_N (both from U1).

PinSignal
PinSignal
Pins 12 (GND) and 24 (VCC) are the package power pins — not declared in the CUPL source. Pin 23 (WRITE_ARM) is a real registered macrocell but is left unconnected on the PCB — internal use only.

Bank register + write-arm

bank_load_en = !IO1_N & !RW BANKn.D = (bank_load_en & Dn) # (!bank_load_en & BANKn) WRITE_ARM.D = (bank_load_en & D7) # (!bank_load_en & WRITE_ARM) .CK = PHI2 .AR = !RESET_N

Loads only on a qualifying $DE00 write; otherwise every bit holds its previous value via feedback. /RESET async-clears BANK0–6 and WRITE_ARM to 0.

Software interface

POKE 56832, n ; bank n (0-127) ; writes OFF POKE 56832, n+128 ; bank n (0-127) ; writes ON (D7=1)

$DE00 = 56832 decimal. A single write both selects the bank and sets the write-arm state — there is no separate unlock address.

Ordering code -90S: 90 ns, S = 44-pin SO (the only two package codes for this part are E = 40-pin TSOP and S = 44-pin SO — there is no "PSOP" option).

AM29F080B notes

  • 8 Megabit, organized 1,048,576 × 8 (1 MB × 8-bit).
  • Single 5 V supply for read, program, and erase.
  • 16 × 64 KB internal erase sectors (SA0–SA15, addressed by A16–A19) — a flash-internal boundary, separate from this board's own 128 × 8 KB bank convention.
  • /CE from /ROML (direct, PCB) · /OE, /WE from U1.

/OE & /WE generation

FLASH_OE_N = !RW FLASH_WE_N = !(WRITE_ARM & !RW & PHI2)

/WE pulses low only while writes are armed, the CPU is writing, and PHI2 is high — ties the pulse to the clock's stable data phase.

R1 (10 kΩ, FLASH_WE_N→VCC) holds /WE high whenever U1 isn't actively driving it low — e.g. during power-up before the GAL is stable.

Bank map — static 8 KB window

CPU-visible window

$8000–$9FFFfixed for every bank
Bank 0flash $000000–$001FFF
Bank 1flash $002000–$003FFF
…
Bank 127flash $0FE000–$0FFFFF

Every bank maps into the same $8000–$9FFF window — BANK0–BANK6 just changes which 8 KB page of the 1 MB flash is currently visible there.

Cartridge mode

/GAME tied directly to +5V, /EXROM tied directly to GND — both hardwired on the PCB, not GAL signals.

Permanently static 8 K. No Ultimax boot phase, no mode-switching bootloader.

Open items (rev 0.3)

  • RY/BY# (flash pin 28) not read by U1 yet.
  • /ROMH (connector pin B) still undefined/unconnected — not needed for static 8K, left open in case that changes.
